# RT Futebol Clube — Media Kit 2026

Projeto estático pronto para hospedagem no Vercel.

## Publicação rápida no Vercel

1. Extraia o arquivo ZIP.
2. Acesse o Vercel e crie um novo projeto.
3. Importe a pasta pelo GitHub ou use o Vercel CLI.
4. Não é necessário configurar framework ou comando de build.
5. O arquivo principal é `index.html`.

## Antes de publicar

No arquivo `index.html`, procure por:

- `https://wa.me/5500000000000`
- `https://instagram.com/`
- `@rtfutebolclube`

Substitua pelos dados oficiais do RT.

## Estrutura

- `index.html`: conteúdo da página
- `style.css`: identidade visual e responsividade
- `app.js`: animações e contadores
- `assets/`: fotos, escudo e patrocinadores
- `vercel.json`: configuração de hospedagem
